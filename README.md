# サボリズム (Saborhythm) ☕⚡

> **「最先端テクノロジーの無駄遣いで、合法的な昼寝とゲームの時間を。」**

リモートワークの普及に伴い、常にPCの前に縛り付けられる現代のIT労働者に贈る、次世代リモートワーク・アリバイ偽装プラットフォーム。
真面目な顔をして高度な無駄技術を全力投球し、あなたのQoLと定時退社を徹底防衛します。

---

## 🛠 主要機能

### 1. ビジー・カモフラージュ (Busy Camouflage)
- **Slack擬似タイピング:** 3分間「入力中...」を点滅させた後に何食わぬ顔で消去。思慮深きエンジニアを演出。
- **意識高い系独り言Bot:** 「認知負荷の低減、これに尽きる。」「マイクロサービスの境界が…」など示唆に富む業界用語を定期自動ポスト。

### 2. パラシュート・ボタン (Emergency Exit)
- **意図的パケットロス:** 会議中にノイズ混入＆映像コマ落ちを発生させ、「家のルーターが爆発しました！」とSlack送信してブラウザ強制終了。
- **うなづきループ・カメラ:** メモを取るフリと真剣なうなづきをループ再生。本人はカップ麺を啜ることが可能。

### 3. パニック・シールド (Panic Shield)
- **0.1秒瞬殺ボス・キー:** 背後の人影を検知した瞬間、YouTube/Steamを巨大Excelと黒い画面（Terminal）で隠蔽。
- **有機的マウス・ジグラー:** タイポやスクロールの迷いなど、人間特有の生々しい挙動を忠実にエミュレート。

### 4. 天変地異・生理現象ジェネレーター
- 当日の天気や曜日、過去の履歴から「愛猫がキーボードの上で液体化して動かせない」「ルンバに足を捕食された」等、追及不能な言い訳をAIが生成。

---

## 🛡 非機能要件・哲学

- **稼働時間:** 平日 09:00〜18:00。休日はシステムの哲学に反するため完全メンテナンス停止。
- **プロセス偽装:** タスクマネージャー上では `System_Critical_Kernel_Update.exe` として動作。
- **軍事レベル暗号化 (AES-256):** サボりログは厳重暗号化され、死後も上司・家族への露見を阻止。
